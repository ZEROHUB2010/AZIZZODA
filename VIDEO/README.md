# ZEROHUB UI — Video & Music Downloader

Мобильное веб-приложение (HTML/CSS/vanilla JS, без фреймворков) в эстетике
Liquid Glassmorphism: тёмный градиент `#0A192F → #2D124D`, неоновый
акцент `#FF6B00`, стеклянные панели, mobile-first (max-width 420px).

## Структура

```
index.html          разметка: сплэш, экраны, модалки, тосты
style.css            вся визуальная система (glass, neon, анимации)
db.js                обёртка над IndexedDB (история, метаданные, статусы)
api.js               API-слой: search / analyzeUrl / getFormats / download —
                      с автоматическим DEMO MODE, если бэкенда нет
app.js                навигация, рендер, download-manager, плеер, тосты
manifest.json         PWA-манифест
service-worker.js     офлайн-кэш оболочки приложения
assets/icons/         SVG-иконки приложения
assets/intro.mp4      ⚠️ не включён в сборку — см. ниже
```

## Про assets/intro.mp4

Видео-интро не сгенерировано (это не то, что можно создать кодом). Файл
`index.html` уже ссылается на `assets/intro.mp4` — просто положите туда
своё видео, и сплэш-экран заработает как описано в ТЗ. Если файла нет,
`app.js` это корректно обрабатывает: по событию `error`, по таймауту и
по `video.readyState === 0` сплэш плавно закрывается и открывается
основной интерфейс — то есть уже сейчас, без видео, приложение открывается
нормально (просто чуть быстрее, чем задумано).

## DEMO MODE

`API_BASE_URL` в `api.js` пустой, поэтому приложение работает в
демонстрационном режиме: поиск и анализ ссылок возвращают тестовые
данные, размеры форматов показываются как «Размер неизвестен» (никогда
не выдумываются), а прогресс загрузки — заметно помеченная имитация
(`... MB/s (демо)` в статистике карточки). Индикатор режима отображается
как бейдж «Демонстрационный режим» над результатами поиска и в тосте
настроек.

## Подключение настоящего backend

1. Укажите origin в `api.js`: `const API_BASE_URL = 'https://ваш-домен';`
2. Реализуйте эндпоинты, которые уже ожидает клиент:
   - `GET /api/search?q=...`
   - `POST /api/analyze` `{ url }`
   - `GET /api/formats?id=...` → реальные размеры файлов
   - `POST /api/download` `{ ... }` → запускает загрузку на сервере
   - `GET /api/download/progress?id=...` → прогресс (для Range-запросов
     и докачки после паузы/разрыва соединения)
3. Интерфейс переключится в реальный режим автоматически — переписывать
   `index.html`/`style.css`/`app.js` не требуется.

## Локальное хранилище

История, метаданные загрузок и статусы хранятся в **IndexedDB**
(`db.js`), не в `localStorage` — это специально сделано так, чтобы
не упереться в лимиты браузера на больших файлах.
